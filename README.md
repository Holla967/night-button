# Get Daddy

A full-screen "come here" button for a phone on the nightstand. Tap anywhere, it runs the
**Get Daddy** Shortcut on the phone (iMessage + FaceTime Audio). Dim amber at night, black background.

Edit the names, hours, and messages at the top of the `<script>` block in `index.html`.
Tap log for the caregiver: open the page with `#log` on the end of the URL.
